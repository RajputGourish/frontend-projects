# 🌳 Linktree Clone

A **Linktree-style personal profile platform** where users can create a single page containing multiple links to share with others.

This project allows users to build a **personal landing page with their important links** such as social media, portfolio, blogs, or any website.

Built using **Next.js, MongoDB, and Tailwind CSS**, this project demonstrates how modern full stack applications manage dynamic user content.

---

## 🚀 Features

- Create a personal profile page
- Add multiple links to share
- Dynamic routing for user profiles
- Store user data and links in MongoDB
- Responsive and modern UI
- Fast performance with Next.js

---

## 🛠 Tech Stack

- **Next.js**
- **React**
- **Tailwind CSS**
- **MongoDB**
- **Node.js (Next.js API Routes)**
- **JavaScript (ES6+)**
